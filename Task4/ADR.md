### <a name="_3bfxc9a45514"></a>**Функциональные требования**
| **№** | **Действующие лица или системы**     | **Use Case**                               | **Описание**                                                                                                                                                                                                                                                    |
|:-----:|:-------------------------------------|:-------------------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|  U1   | Оператор кол-центра                  | Консультация клиентов по ставкам депозитов | 1. Клиент обращается в кол-центр для консультации по депозитам.<br/>2. Оператор кол-центра просматривает ставки по депозитам в системе кол-центра<br/>3. Система кол-центра запрашивает ставки у сервиса "Реестр ставок"<br/> 4. Оператор консультирует клиента |
|  U2   | Реестр ставок, Партнерский кол-центр | Консультация клиентов по ставкам депозитов | 1. Один раз в час по расписанию сервис Реестр ставок формирует файл с реестром ставок по депозитам и отправляет его на SFTP сервер <br/>2. Система партнерского кол-центр считывает файл и загружает в свою систему                                             |
|  U3   | Оператор партнерского кол-центра     | Консультация клиентов по ставкам депозитов | 1. Клиент обращается в кол-центр для консультации по депозитам.<br/>2. Оператор кол-центра просматривает ставки по депозитам в системе кол-центра<br/> 3. Оператор консультирует клиента                                                                        |
### <a name="_u8xz25hbrgql"></a>**Нефункциональные требования**

| **№** |**Требование**|
|:-----:| :- |
|   1   |Все сервисы должны работать 24/7 и быть доступны в 99,9% случаев|
|   2   |База данных системы АБС перегружена, поэтому ужно избежать прямой работы кол-центров с АБС|
|   3   |У партнерского кол-центра нет возможности сделать API-вызовы, но он может работать через файлы, переданные например по SFTP|
|   4   |Передача файлов должно быть по защищенному протоколу|

### <a name="_bjrr7veeh80c"></a>**Альтернативы**
Как альтернатива для партнерского кол-центра можно отпрвлять файлы на почту, вместо SFTP сервера

**Недостатки, ограничения, риски**
* Файл не выгружается вовремя, тогда у операторов будет устаревшая информация из старого файла, возможно стоит добавить версию для файла или срок действия
* Риск подмены данных в файле на стороне партнерского кол-центра, нужно ограничивать доступ к ресурсу
